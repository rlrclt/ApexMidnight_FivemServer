# 📊 เปรียบเทียบ Base / Framework ยอดนิยมใน FiveM

เอกสารเปรียบเทียบจุดเด่น ข้อดี-ข้อเสีย ของแต่ละ Base ในวงการ FiveM เพื่อใช้เป็นแนวทางในการเลือกและพัฒนาเซิร์ฟเวอร์

---

## 1. ESX (ESX Legacy) — ยอดนิยมอันดับ 1 ในเซิร์ฟไทย

| หัวข้อ | รายละเอียด |
| :--- | :--- |
| **ความนิยม** | เซิร์ฟเวอร์ในไทยประมาณ 80 - 90% ใช้ Base นี้ |
| **จุดเด่น** | • สคริปต์ภาษาไทยในตลาดมีเยอะที่สุด (สคริปต์ฟรี, สคริปต์แจก, ตลาดซื้อขายในไทย)<br>• ระบบแนวไทยพร้อมใช้เยอะมาก (กระเป๋า UI ไทย, กาชาปอง, อาชีพเสริม, แฟชั่น, แก๊งตีกัน)<br>• มี Developer และคอมมูนิตี้ในไทยให้ปรึกษาและจ้างงานได้ง่าย |
| **ข้อจำกัด** | • สถาปัตยกรรมโค้ดเป็นรุ่นเก่า (Legacy) หลายระบบยิง Query ฐานข้อมูลหนัก<br>• หากคนออนเกิน 64+ หรือใส่สคริปต์ที่เขียนไม่ดี เซิร์ฟเวอร์จะกินแรม CPU และกระตุกง่าย<br>• ระบบความปลอดภัยและการป้องกันโปร/สแปม Trigger ต้องคอยติดตั้งตัวกันโปรเสริม |

---

## 2. QBCore — มาตรฐานเซิร์ฟเวอร์สากล (Global Standard)

| หัวข้อ | รายละเอียด |
| :--- | :--- |
| **ความนิยม** | นิยมสูงสุดในเซิร์ฟเวอร์ต่างประเทศ (ยุโรป / อเมริกา) |
| **จุดเด่น** | • โครงสร้างโค้ดเป็นระเบียบ สะอาดและทันสมัยกว่า ESX รุ่นเก่า<br>• รองรับระบบ Multi-character, ระบบอาชีพ/เกรด, และ Item Metadata ดีตั้งแต่เริ่ม<br>• มีสคริปต์คุณภาพสูงในตลาดต่างประเทศ (Tebex, GitHub) รองรับเยอะมาก |
| **ข้อจำกัด** | • สคริปต์สำเร็จรูปที่เป็นภาษาไทยยังมีน้อยกว่าฝั่ง ESX<br>• กระเป๋าเดิม (`qb-inventory`) กินทรัพยากรค่อนข้างสูง (ปัจจุบันหลายเซิร์ฟเปลี่ยนไปใช้ `ox_inventory` แทน) |

---

## 3. Qbox (Qbox Project) — Base  (Next-Gen High Performance)

| หัวข้อ | รายละเอียด |
| :--- | :--- |
| **ความนิยม** | Base ยุคใหม่ที่พัฒนาต่อยอดโดยร่วมมือกับทีม **Overextended (OX Stack)** |
| **จุดเด่น** | • **กินทรัพยากรต่ำที่สุด (Resmon 0.01 - 0.03 ms)** เซิร์ฟเวอร์เสถียรและลื่นไหลสูงมาก<br>• ระบบความปลอดภัย Server-Side สูงที่สุด ป้องกันการเสกของ/เสกเงิน/โปรโมบาย<br>• รองรับระบบ **OX Stack** เต็มระบบ (`ox_inventory`, `oxmysql`, `ox_target`, `ox_lib`) ของไม่หายแน่นอน<br>• **มี Bridge ในตัว**: สามารถนำสคริปต์ของ **QBCore** ส่วนใหญ่มาเปิดใช้งานบน Qbox ได้โดยตรง |
| **ข้อจำกัด** | • ยังค่อนข้างใหม่ในไทย สคริปต์สำเร็จรูปภาษาไทยสำเร็จรูปต้องนำมาแปลหรือคอนฟิกเพิ่มเติม |

---

## 4. OX Core (Pure Standalone)

| หัวข้อ | รายละเอียด |
| :--- | :--- |
| **ความนิยม** | เหมาะกับทีมนักพัฒนาขั้นสูง (Hardcore Developers) |
| **จุดเด่น** | • แกนหลักเพียวๆ ตัดระบบส่วนเกินออกทั้งหมด เพื่อประสิทธิภาพสูงสุดแบบไร้ขีดจำกัด |
| **ข้อจำกัด** | • ไม่มีระบบสำเร็จรูปมาให้เลย (ต้องเขียนสคริปต์เองเกือบ 100%) ไม่เหมาะกับเซิร์ฟที่ต้องการเปิดใช้งานไว |

## 💡 คำแนะนำในการเลือกใช้งาน
1. **ถ้าเน้นเปิดไว สคริปต์ไทยสำเร็จรูปเยอะ กาชาปอง แฟชั่นไทยเกลื่อนตลาด** ➔ เลือก **ESX Legacy**
2. **ถ้าเน้นเสถียร ลื่นไหล ไม่แล็ก คนเยอะของไม่หาย ปลอดภัยจากโปรสูง และต่อยอดได้ยาว** ➔ เลือก **Qbox + OX (ตัวปัจจุบัน)** ดีที่สุด
