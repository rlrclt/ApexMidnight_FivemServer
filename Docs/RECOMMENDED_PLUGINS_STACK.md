## 🏛️ 1. ระบบแกนกลางเซิร์ฟเวอร์ (Server Infrastructure)
*ชุดนี้คือฐานรากที่ทุกระบบต้องใช้ร่วมกัน ติดตั้งผ่าน txAdmin Recipe ของ Qbox*

- **oxmysql:** จัดการฐานข้อมูล เร็วและปลอดภัยที่สุด

- **qbx_core:** ระบบแกนหลัก (ข้อมูลผู้เล่น, ตัวละคร, สิทธิ์)
- **pma-voice:** ระบบเสียงสมจริง (ระยะเสียงไมค์, วอตำรวจ/หมอ, วิทยุแก๊ง)
- **illenium-appearance:** ระบบสกิน ตัวละคร เสื้อผ้า บันทึกชุดยูนิฟอร์ม
- **ox_doorlock:** ระบบล็อกประตูสถานีตำรวจ โรงพยาบาล อู่ช่าง และบ้าน

## 🗄️ 7. สถาปัตยกรรมฐานข้อมูลและระบบเครือข่าย (Database & Networking Architecture)

### 7.1 Database Stack (เร็วและเสถียรที่สุดใน FiveM)
ระบบจัดเก็บข้อมูลหลักใช้คอมโบระดับท็อป: **MariaDB 11.x + oxmysql**

```
[ FiveM Server / Lua Scripts ]
             │
             ▼ (Non-blocking / Asynchronous)
         [ oxmysql ]
             │
             ▼ (Zero Network Latency ผ่าน Unix Domain Socket)
      [ /run/mysqld/mysqld.sock ]
             │
             ▼
      [ MariaDB 11.8+ ]
```

- **Database Engine:** `MariaDB 11.8`
  - กิน RAM น้อยกว่า MySQL 8.0 ประมาณ 30-40%
  - Query Optimizer บน Linux ทำงานได้รวดเร็วกว่า
  - การเข้ารหัสภาษา: `utf8mb4_unicode_ci` (รองรับภาษาไทย 100% ไม่เพี้ยน)
- **Database Driver:** `oxmysql`
  - พัฒนาบน Node.js `mysql2` รันแบบ Asynchronous ไม่ดึง Game Thread ให้กระตุก
  - มี Prepared Statements Cache และ Connection Pool ในตัว
  - รองรับ Auto-Migration (สร้าง Table ให้อัตโนมัติเมื่อเปิด Resource)
- **การเชื่อมต่อความเร็วสูงสุด (Unix Domain Socket Optimization):**
  - เชื่อมต่อผ่าน Local Socket ข้าม TCP Overhead ลด Latency ได้อีก 15-20%
  ```cfg
  # ตัวอย่างใน server.cfg:
  set mysql_connection_string "mysql://fivem:PASSWORD@localhost/fivem_roleplay?socketPath=/run/mysqld/mysqld.sock&charset=utf8mb4"
  ```

### 7.2 การเปรียบเทียบ oxmysql vs Socket.io vs Native Networking
ทำความเข้าใจหน้าที่ที่ถูกต้องเพื่อประสิทธิภาพสูงสุด:

| ประเภท | เทคโนโลยีที่เลือกใช้ | บทบาทและหน้าที่ | เหตุผล |
| :--- | :--- | :--- | :--- |
| **ฐานข้อมูล (Storage)** | **oxmysql + Unix Socket** | บันทึกข้อมูลถาวร (เงิน, ของ, รถ, ผู้เล่น) | เร็วที่สุด มี Transaction ปลอดภัย และไม่หน่วง Tick เกม |
| **เครือข่ายในเกม (Game Networking)** | **CitizenFX Native Events & State Bags** | สื่อสารระหว่างผู้เล่นกับเซิร์ฟเวอร์ในเกม | ใช้ UDP/ENet (C++) ระดับ Microsecond ไวกว่า WebSocket มาก |
| **เชื่อมต่อภายนอก (External Web)** | **Socket.io / WebSockets** *(ใช้เฉพาะกรณีจำเป็น)* | เชื่อมต่อข้อมูลเกมออกไปเว็บเบราว์เซอร์จริง เช่น Web CAD/MDT ตำรวจ หรือ Live Map หน้าเว็บ | ไม่นำมาใช้เป็นฐานข้อมูล เพื่อป้องกัน Overhead และอาการแล็ก |
