เครื่องมือคำนวณอัตราทดเกียร์ & แรงบิด (FiveM Drivetrain Simulator)

คำนวณแม่นยำ 100% ตรงตามฟิสิกส์ใน veh_drivetrain/client.lua และ handling.meta
1. ข้อมูลพื้นฐานจาก handling.meta
ชื่อสปอว์นรถ เช่น elegy, thrax, sultan
ความเร็วสูงสุดใน handling.meta (สคริปต์จะอ้างอิงค่าจริงจากรถแต่ละคันโดยตรง)
ค่าแรงบิดหลักจาก handling.meta (ฐาน 1.0x)
จำนวนเกียร์ที่ต้องการให้รถมีในเกม
2. การตั้งค่ารอบเครื่องยนต์ (RPM Specs)
Cam Lope เสียงหอบ (เช่น ±80)
รอบต่อวินาที (1.0 = ทั่วไป)
0.18 = ตัดรอบไวแบบไฮเปอร์คาร์, 0.85 = หน่วงนุ่มนวลแบบสปอร์ต
พรีเซ็ตสไตล์การขับขี่
ตารางคำนวณแต่ละเกียร์ (Exact Physics Formula)
เกียร์ สัดส่วน (Ratio) ความเร็วตัดเกียร์ รอบสับขึ้น (Upshift) รอบสับลง (Downshift) แรงดึงจริง (Force) รอบตก (Drop RPM)
กราฟช่วงความเร็วของแต่ละเกียร์ (Speed Coverage)
โค้ด Config สำหรับนำไปใช้งาน (คัดลอกใส่ config.lua ได้ทันที)
